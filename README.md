# WAIP RUSSIA Forum v2

Запуск: `npm install && npm start` (порт из PORT, по умолчанию 3000).

## Railway — чтобы аккаунты НЕ пропадали
1. Dockerfile, package.json, server.js, version.json, папка public — в КОРНЕ репозитория.
2. Сервис -> Settings -> Volumes -> Add Volume, Mount Path: `/data` (один раз).
   Форум сам найдёт папку (DATA_DIR задавать не обязательно). Если Volume не подключён, в админ-панели будет красное предупреждение.
3. Первый зарегистрированный пользователь становится главным администратором.

## Как обновлять форум
Залейте новые файлы (деплой). Данные не трогаются: перед каждым обновлением форум сам делает копию базы.
У открытых страниц сверху появится окно «Доступно обновление» с кнопкой «Обновить».
Чтобы в окне были свои заметки, правьте `version.json` (поднимите version и впишите notes).

## Резервные копии
Админ-панель -> «Хранилище и резервные копии»: скачать, создать, восстановить из файла или из копии на сервере.

Переменные: DATA_DIR, TELEGRAM_URL, DISCORD_URL, NODE_ENV=production.
